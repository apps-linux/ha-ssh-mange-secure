# ha-ssh-mange-secure

Home Assistant add-on repository. Add this repo's URL under
**Settings → Add-ons → Add-on Store → Repositories** in Home Assistant to
install the add-on below.

## Add-ons

- [`ssh_docker_manager`](ssh_docker_manager/README.md) — securely manage
  Docker containers on a remote Linux host over SSH, exposed to Home
  Assistant via MQTT.
